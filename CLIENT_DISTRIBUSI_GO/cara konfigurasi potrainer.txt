Berikut adalah langkah-langkah memasukkan file docker-compose.yml PrintServer ke dalam Portainer sebagai Stack:

🚀 Cara 1: Menggunakan Git Repository di Portainer (Paling Praktis & Otomatis)
Portainer memiliki fitur untuk langsung membaca dan me-build repositori GitHub secara otomatis.

Buka dashboard Portainer Anda (http://SERVER_IP:9000 atau port Portainer Anda).
Pilih environment Docker Anda (contoh: local).
Di menu sebelah kiri, klik Stacks → lalu klik tombol + Add stack.
Pada kolom Name, ketik: printserver.
Pada pilihan Build method, pilih Repository.
Isi formulir repositori berikut:
Repository URL:
https://github.com/ramadhan24021996/PrintServer.git
Repository reference:
refs/heads/main
Compose path:
docker-compose.yml
Scroll ke bawah dan klik tombol Deploy the stack.
Proses: Portainer akan otomatis melakukan git clone, mem-build Dockerfile, dan menjalankan kontainer PrintServer secara otomatis.

📝 Cara 2: Menggunakan Web Editor Portainer (Manual Stack)
Jika Anda ingin menempelkan (copy-paste) kode YAML langsung di Portainer Web Editor:

Masuk ke Portainer → Stacks → + Add stack.
Beri nama: printserver.
Pilih Web editor, lalu tempelkan kode skrip berikut:
yaml
version: '3.8'
services:
  printserver:
    build: .
    container_name: printserver
    restart: unless-stopped
    network_mode: host # Disarankan Host mode agar SNMP discovery & CUPS broadcast berfungsi
    environment:
      - PORT=3003
      - SCAN_DIR=/opt/scans
      - USERS_FILE=/app/data/users.json
      - DATA_FILE=/app/data/printers.json
      - SETTINGS_FILE=/app/data/settings.json
      - SESSIONS_FILE=/app/data/sessions.json
      - ALERT_STATE_FILE=/app/data/alert-state.json
    privileged: true
    volumes:
      - printserver_data:/app/data
      - printserver_scans:/opt/scans
      - /var/run/cups/cups.sock:/var/run/cups/cups.sock
      - /dev/bus/usb:/dev/bus/usb
volumes:
  printserver_data:
  printserver_scans:
Klik Deploy the stack.
🔍 Catatan Penting untuk Portainer:
network_mode: host: Diperlukan agar fitur SNMP auto-discovery printer di LAN dan layanan CUPS dapat berkomunikasi secara langsung di jaringan lokal server.
Volume Mount: Data printer (printers.json), user, dan file scan akan otomatis disimpan ke dalam volume Docker printserver_data dan printserver_scans, sehingga data tetap aman meskipun Stack di-restart atau di-update.
