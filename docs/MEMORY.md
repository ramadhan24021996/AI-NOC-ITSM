# Memory

## Architecture
Memory is intended to be split into several layers:
- **Episodic:** Timeline of events.
- **Semantic:** Fact-based knowledge.
- **Procedural:** How-to playbooks.
- **Case-Based:** Similarity matching.

## Current Status (STUB)
The `SERVER/python_ai_core/cognitive_memory/` directory contains 9 files that are currently pure stubs (empty methods or `pass`). True cognitive memory between sessions is not yet implemented in production.

RAG (`knowledge_vectors`) currently serves as the primary factual memory.
