# OSI AI Ops Incident Analysis Platform

## Introduction
OSI AI Ops is an autonomous AI-driven Network Operations Center (NOC) platform designed for automated incident detection, root cause analysis, mitigation, and learning across Windows and Linux fleets.

## Features
- Real-time telemetry ingestion
- Auto OSI layer classification (L1-L7)
- Multi-model LLM consensus (Gemini, Groq, DeepSeek)
- OPA-style policy evaluation
- Human-in-the-Loop (HITL) approval gates
- Automated remediation execution
- Continuous learning via RAG (Retrieval-Augmented Generation)
